# XXL-Boot React 版（xxl-boot-ui-react2）技术方案

> 基于 [ant-design-pro](https://github.com/ant-design/ant-design-pro)（v6.0.2，位于 `/Users/admin/program/git-space/project/ant-design-pro`）实现，后端统一对接 xxl-boot-api，接口与数据结构不改动。

---

## 一、目标与范围

在 `xxl-boot-ui-react2/` 下新建 React 前端工程，**完全遵循 ant-design-pro 的代码结构、组件规范、设计规范与主题体系**；业务功能与 `xxl-boot-ui`（Vue 版）保持一致，后端接口原样对接。

| 模块 | 页面 | 说明 |
| --- | --- | --- |
| 认证 | 登录 | 账号密码 + 验证码（开关由后端控制）+ 记住密码（token 有效期） |
| 个人中心 | 基本信息 / 修改密码 | `/user/profile`，从头像下拉进入 |
| 首页 | Dashboard | 指标卡片 + 审计日志趋势图 + 站内消息 |
| 权限管理 | 用户管理 / 角色管理 / 资源管理 / 组织管理 | 含按钮级权限、资源-角色授权树 |
| 系统管理 | 字典管理 / 配置管理 / 站内消息 / 审计日志 | 含字典数据页、消息富文本、日志导出 |
| 系统工具 | 代码生成 / 表单构建 | 代码生成对接后端；表单构建为纯前端设计器 |
| 帮助中心 | /help | 静态页 |

## 二、技术选型

全部沿用 ant-design-pro 既有依赖，仅在个别场景补充必要依赖（与 Vue 版功能对齐）：

| 能力 | 方案 | 说明 |
| --- | --- | --- |
| 框架 | `@umijs/max` ^4.6.75（同 ant-design-pro 6.0.2） | 保留全部插件：layout / initialState / access / model / request / antd / locale / reactQuery / moment2dayjs |
| 组件库 | `antd` ^6 + `@ant-design/pro-components` | ProTable / ProForm / ModalForm / DrawerForm / ProLayout / PageContainer 等 |
| 图表 | `@ant-design/plots`（已内置） | 首页日志趋势 Line 图，替代 Vue 版 echarts |
| 富文本 | `react-quill`（新增） | 站内消息编辑，对齐 Vue 版 `@vueup/vue-quill`，内容为 HTML |
| 拖拽 | `@dnd-kit/core` + `@dnd-kit/sortable`（新增） | 表单构建画布、代码生成字段排序 |
| 请求 | umi `request` 插件（axios 内核） | 在 `requestErrorConfig.ts` 适配 xxl-boot `Response` 结构 |
| 会话存储 | `js-cookie`（新增，类型 `@types/js-cookie`） | 与 Vue 版一致：Cookie `Admin-Token`，请求头 `xxl-sso-login-token` |
| 剪贴板 | `navigator.clipboard` + `execCommand` 兜底 | 日志详情/代码预览复制 |
| Node | >= 22 | ant-design-pro 要求 |

## 四、全局基础设施改造

> 原则：**沿用 ant-design-pro 的机制与文件位置，只在适配层做业务化改造**，不引入额外框架。

### 4.1 路由表（`config/routes.ts`）

按 XXL-Boot 业务重写，结构遵循 ant-design-pro 规范（path/name/icon/component/routes/redirect/access）：

```ts
export default [
  { path: '/user', layout: false, routes: [
      { path: '/user/login', name: 'login', component: './user/login' },
      { path: '/user/profile', name: 'profile', component: './user/profile' }, // 隐藏于菜单
      { path: '/user', redirect: '/user/login' },
      { component: './exception/404', path: '/user/*' },
  ]},
  { path: '/dashboard', name: 'dashboard', icon: 'home', component: './dashboard' },
  { path: '/authz', name: 'authz', icon: 'team', access: 'canAuthz',
    routes: [
      { path: '/authz', redirect: '/authz/user' },
      { path: '/authz/user', name: 'user', component: './authz/user', access: 'canAuthzUser' },
      { path: '/authz/role', name: 'role', component: './authz/role', access: 'canAuthzRole' },
      { path: '/authz/resource', name: 'resource', component: './authz/resource', access: 'canAuthzResource' },
      { path: '/authz/org', name: 'org', component: './authz/org', access: 'canAuthzOrg' },
    ]},
  // system（dict / config / message / log）、tool（codegen / pagegen）、help 同理
  { path: '/system/dict/data', name: 'dict-data', component: './system/dict-data',
    hideInMenu: true, access: 'canSystemDict' }, // 隐藏路由，字典数据页
  { path: '/', redirect: '/dashboard' },
  { component: './exception/404', path: '/*' },
]
```

- 各分组父路由补 `redirect` 到首个子页面（ant-design-pro 惯例）。
- `/user/profile` 通过 `hideInMenu: true` 隐藏（头像下拉进入），对齐 Vue 的 hidden 路由。
- 页面级权限用 `access` 字段（见 4.4）。

### 4.2 请求层适配（`src/app.tsx` 的 `request` + `src/requestErrorConfig.ts`）

xxl-boot 后端统一返回 `{ code, msg, data }`（200 成功），分页为 `PageModel{ data, total }`。ant-design-pro 默认信封是 `{ success, data, errorMessage }`，需改造：

- **errorThrower**：`code !== 200` 时抛 `BizError`（携带 `msg`）。
- **errorHandler**：
  - `code === 301` → 弹"登录状态已过期"确认框 → 退出并回登录页（对齐 Vue 的 301 重登逻辑，`isRelogin.show` 防重弹）。
  - 其他非 200 → `message.error(msg)`。
  - HTTP 层异常：Network Error → "后端接口连接异常"、timeout → "系统接口请求超时"、状态码异常 → "系统接口{code}异常"（对齐 Vue）。
- **requestInterceptors**：
  - 注入 token：有 Cookie token 且 `headers.isToken !== false` 时加 `xxl-sso-login-token` 头（对齐 Vue）。
  - 参数序列化：配置 `paramsSerializer`，数组输出 `ids[]=1&ids[]=2`、嵌套对象展开为 `key[sub]=val`（对齐 Vue `tansParams`）。
  - 防重复提交：POST/PUT 基于 sessionStorage 快照（url+data+params+time < 1s 判重，`repeatSubmit:false` 跳过），对齐 Vue。
- **baseURL**：`'/api'`，服务层接口路径与 Vue 完全一致（如 `/auth/login`）；开发期由 proxy 剥掉 `/api` 转发到后端。

### 4.3 会话与登录态

- **token 存储**（`src/utils/auth.ts`）：`js-cookie`，key `Admin-Token`，header key `xxl-sso-login-token`，与 Vue 一致。登录成功后 `rememberMe ? 365天 : 2/24天` 有效期。
- **会话 model**（`src/models/user.ts`，umi model 插件，对齐 antd-pro 数据流规范）：
  - `state`：`token / userId / userName / realName / roles / permissions / menus`
  - `actions`：`login(params)`（校验→调 `/auth/login`→存 token）、`getInfo()`（`/auth/loginCheck` → 回填 id/name/roles/permissions）、`logout()`、`hasPermi` / `hasRole`（含 `*:*:*` 与 `admin` 兜底，逻辑与 Vue user store 一致）、`initRouters()`（`/getRouters` → 存菜单树）。
- **getInitialState**（`src/app.tsx`）：非登录页时 `fetchUserInfo`（`/auth/loginCheck`，`skipErrorHandler:true`）失败即回登录页；成功后并行拉取 `/getRouters` 存入 `initialState.menuData`。`onPageChange` 未登录统一回登录页。

### 4.4 权限体系（`src/access.ts` + 按钮级）

- 路由级：`access.ts` 基于 `permissionList` 生成访问键（`canAuthzUser` 等），路由 `access` 字段控制页面可见与越权跳转。
- 按钮级：`usePermission` hook（内部读 user model），提供 `hasPermi('authz:user')` / `hasRole('admin')`，渲染前过滤操作按钮。**各页面按钮的权限字符串与 Vue 版完全一致**：
  - 用户/角色/资源/组织：`authz:user` / `authz:role` / `authz:resource` / `authz:org`；
  - 配置/字典/日志/消息/代码生成：Vue 版用 `hasRole('admin')`，React 保持一致。

### 4.5 菜单渲染（对齐后端资源配置）

- 菜单数据源：后端 `/getRouters` 返回的树（`RouterVo{ name, path, hidden, component, meta{title,icon}, children }`）。
- 实现：`layout` 运行态配置的 `menuDataRender`，将 `initialState.menuData` 转换为 ProLayout 菜单项：
  - `hidden` 过滤、`children` 递归、菜单名取 `meta.title`（后端管理，与 Vue 一致）；
  - **图标映射**：后端 icon 目前存的是遗留 `fa-*` 值（如 `fa-home`），建立映射表（`fa-home→HomeOutlined`、`fa-users→TeamOutlined`、`fa-cogs→SettingOutlined`、`fa-wrench→ToolOutlined`、`fa-book→BookOutlined` 等）→ antd 图标，未命中兜底默认图标；
  - 点击跳转：`<Link to={path}>`（与 ant-design-pro `menuItemRender` 一致）。

### 4.6 国际化

- 保留 ant-design-pro 的 locale 插件与 `src/locales/` 目录结构，设置 `default: 'zh-CN'`、`baseNavigator: false`（业务为中文，对齐 Vue）。
- 页面文案统一用 `intl.formatMessage({ id, defaultMessage })` / `<FormattedMessage>`，defaultMessage 即中文（与 Vue 一致），zh-CN 补齐新增 key；其余语言包可选镜像。

## 五、登录页（`src/pages/user/login/index.tsx`）

- **样式**：完全沿用 ant-design-pro `LoginForm` 布局（居中卡片、logo、标题、底部 Footer），使用 `createStyles` 主题化。
- **表单**：`ProFormText`（账号，UserOutlined）+ `ProFormText.Password`（密码）+ 验证码（`enable=true` 时显示：输入框 + 点击刷新的图片）+ `ProFormCheckbox`（记住密码）+ 登录按钮（loading）。
- **验证码**：挂载时 `GET /auth/captcha`，`res.data.enable` 控制显示，`uuid` 回填，`image` 展示，点击重新获取；登录失败时刷新验证码（对齐 Vue）。
- **登录逻辑**（对齐 Vue user store）：
  1. 表单校验通过 → `user.login({ username, password, captchaUuid, captchaResult, rememberMe })`；
  2. 成功后 `fetchUserInfo()` 更新 `initialState.currentUser`，并行 `initRouters()`；
  3. 安全重定向到 `?redirect=`（ant-design-pro 的 `getSafeRedirectUrl` 防开放重定向）或 `/dashboard`；
  4. 失败：`message.error(msg)`，刷新验证码。
- 移除 ant-design-pro 的注册/手机号登录/忘记密码等无关内容，保留登录页 Footer（替换为 XXL-Boot 版权 + xuxueli 官网/GitHub 链接，对齐 Vue 登录页底部）。

## 六、个人中心（`/user/profile`）

- **布局**（对齐 Vue 结构、采用 antd 组件）：左侧 `Card` 展示"个人信息"（`Descriptions`：用户账号 / 手机号 / 邮箱 / 所属部门 / 所属角色 / 创建日期，数据来自 `GET /authz/user/loadProfile`）；右侧 `Card` + `Tabs`（基本资料 / 修改密码）。

- **修改密码**（`resetPwd`）：旧密码 / 新密码 / 确认密码，校验对齐 Vue（必填 + 两次一致 + 密码规则），提交 `POST /authz/user/updatePwd?oldPassword=&newPassword=`，成功提示并清空表单。
- 顶部入口：AvatarDropdown 菜单项"个人中心" → `/user/profile`。

## 八、页面实现清单

> 通用约定（全部页面遵循）：
> - 分页：服务层封装 `current/pageSize → offset/pagesize` 转换，ProTable `request` 返回 `{ data: response.data.data, total: response.data.total, success: true }`；
> - 枚举下拉：统一 `loadEnumItem('XxxEnum')` 缓存加载（`GET /system/dict/loadEnumItem`）；
> - 树表：后端返回平铺数组 → `handleTree` 转树，inline 排序保存走 `updateSort(ids[], orders[])` 差量提交；
> - 删除：`Modal.confirm` + `ids[]` 数组参数；
> - 权限按钮：`usePermission().hasPermi/hasRole` 控制显隐；
> - 类型定义统一收敛到 `services/xxl-boot/typings.d.ts`（`declare namespace API`）。

### 8.1 首页 Dashboard（`/dashboard`）
- 指标卡片 ×4：`Card` + `Statistic`（用户/角色/日志/消息数量，图标色块对齐 Vue），`GET /dashboard/stats`。
- 日志趋势：`@ant-design/plots` Line（平滑 + 面积渐变），`Radio.Group` 7/14/30 天切换；后端 `[{date,count}]` 补全连续日期、无数据补 0（逻辑对齐 Vue）。
- 站内消息：`GET /system/message/listTop` 列表 + 点击打开消息详情抽屉（`markRead`）。

### 8.2 用户管理（`/authz/user`，权限 `authz:user`）
- 左侧组织树面板 `TreePanel`（搜索过滤），点击收集子孙 orgId 过滤（`orgIds` 逗号串）；右侧 `ProTable`。
- 列：多选、id、username（链接→详情 Drawer）、realName、orgName、状态 `Switch`（0/1，调用 update）、addTime；操作：修改 / 删除 / 更多→重置密码。
- 新增/编辑 `ModalForm`：username（新增必填，编辑禁用，正则对齐）、password（仅新增，默认 123456）、realName、roleIds（多选，status=1 禁用）、orgId（TreeSelect）、email、phone、status；提交剥离 `addTime/updateTime/orgName/roleNames`，`orgId` 空转 0。
- 重置密码：`Modal.confirm` 输入新密码（4-20）→ 复用 update。
- 用户详情 Drawer：基础信息 + 角色名（由 roleIds 反查）+ 状态/时间。

### 8.3 角色管理（`/authz/role`，权限 `authz:role`）
- `ProTable`：id/name/code/order/status/addTime；新增/修改/删除。
- `ModalForm`（680 宽）：name、code（必填）、order、status + 菜单权限 `Tree`（`resource/treeList` 全量转树；支持展开/折叠、全选/全不选、父子联动 `checkStrictly` 切换——对齐 Vue 的三个 checkbox）。
- 授权回显：`GET /authz/role/loadRoleRes?roleId=` 返回已授权 id 集合 setChecked。
- 保存：add → 用返回的新 id 调 `updateRoleRes`；update → `updateRole` + `updateRoleRes`（提交 checked + halfChecked 的 id 集合）。

### 8.4 资源管理（`/authz/resource`，权限 `authz:resource`）
- 树表：name（图标+文本）、type Tag（目录/菜单/按钮）、inline order、permission、url、visible、status；行操作：修改/新增(仅非按钮)/删除。
- `ModalForm`（680 宽）：parentId（TreeSelect 含根节点）、type（radio）、name、order、icon（`IconSelect`，type≠按钮时显示）、url（type≠按钮）、permission、visible、status；校验对齐 Vue（name/order 必填）。
- inline 排序：加载时快照，保存时 diff 差量调 `updateResourceSort(ids[], orders[])`；展开/折叠全部。

### 8.5 组织管理（`/authz/org`，权限 `authz:org`）
- 树表：name、inline order、status Tag、manager、addTime；行操作：修改/新增(子)/删除（parentId≠0 才能删）。
- `ModalForm`：parentId（TreeSelect，根节点隐藏）、name、order、manager、status；提交前做防环校验（不可选自身及子孙为父）。

### 8.6 字典管理（`/system/dict` + `/system/dict/data`，权限 `system:dict`）
- 字典类型页：`ProTable`（id/name/type/status/remark/addTime）；`ModalForm`（name、type 必填，type 编辑禁用、正则对齐）；行"列表"→ 打开隐藏路由 `/system/dict/data?dictId=`；type 列链接 → 字典数据抽屉 `DictDataDrawer`（统计卡片 + 分页列表）。
- 字典数据页：头部展示字典名（`load`），`ProTable`（itemPageList，dictId 来自 query）；`ModalForm`（name、code 纯数字 1-10000000 且编辑禁用、status、order、remark）；"关闭"返回字典列表。

### 8.7 配置管理（`/system/config`，权限 admin 角色）
- `ProTable`（id/name/key/value/status/remark/addTime）；`ModalForm`：name、key（编辑禁用，正则对齐）、value textarea、status、remark；标准 CRUD。

### 8.8 站内消息（`/system/message`，权限 admin 角色）
- `ProTable`：id/title（链接→详情抽屉）/category Tag/status Tag/sender/addTime；行操作：阅读用户 / 修改 / 删除。
- `ModalForm`（780 宽）：title、category（select）、status、content（`react-quill` 富文本，min-height 192，对齐 Vue Editor）。
- 已读用户 Dialog：`GET /system/message/readUsers` 分页（userName/realName/阅读时间）。
- 详情抽屉复用公共 `MessageDetail`。

### 8.9 审计日志（`/system/log`，权限 admin 角色）
- `ProTable`：id/type Tag/module（枚举 map）/title/operator/IP（`ipAddress||ip`）/addTime；筛选：type、module（默认 0=全部）、title。
- 导出：`download('system/log/export', params, 'log_'+Date.now()+'.xlsx')`（POST → blob 保存，参数 form-urlencoded，对齐 Vue download 工具）。
- 详情 Dialog：基本信息 + 操作人信息 + 日志内容（`<pre>` + 复制按钮）。

### 8.10 代码生成（`/tool/codegen`，权限 admin 角色）
- `ProTable`：index/tableName/tableComment/addTime/updateTime；操作：编辑/删除/预览/生成代码；工具栏：新增（创建表）/生成代码（批量）。
- 创建表 Dialog：`tableSql` textarea（预置演示 SQL）→ `POST /tool/codegen/createTable`。
- 编辑 Dialog（90% 宽，两个 Tabs）：
  - 配置信息：tableName/tableComment + packageName/moduleName/businessName/functionName/functionAuthor/formColNum(1/2/3)/tplCategory(crud/tree)/tplWebType(element-plus-typescript)/remark；双表单校验；
  - 字段信息：可拖拽排序表格（`@dnd-kit/sortable`），列含 columnName（只读）/columnComment/javaType/javaField/isInsert/isEdit/isList/isQuery/queryType/htmlType/isRequired/dictType（`queryDictList` 数据），`sort=i+1`；id 字段强制 isInsert/isEdit='0'。
- 提交：`POST /tool/codegen/update`（`{...info, fieldList}`）。
- 预览 Dialog：按模板文件 Tabs（文件名去 `.ftl` 后缀做 label）+ 复制 + `<pre>` 展示。
- 生成代码：`GET /tool/codegen/batchGenCode?ids=x&ids=y` → zip 下载（`xxl-boot-codegen.zip`）。

### 8.11 表单构建（`/tool/pagegen`，权限 tool:pagegen）
- 三栏布局：左 = 组件面板（输入型/选择型/布局型，分组展示、可拖拽/点击添加）；中 = 画布（antd `Form` 实时预览，`Row/Col` 布局，工具栏：导出 TSX / 复制代码 / 清空 / 撤销删除）；右 = 属性面板（选中组件属性 or 表单全局属性，支持组件类型切换）。
- 交互：组件克隆添加、画布内拖拽排序（`@dnd-kit`）、复制、删除；ID 全局自增；label 变更自动同步 placeholder。
- 代码生成：`@dnd-kit` 设计器数据 → React/TSX 模板（`utils/generator/`：html/js/css 模板改为 TSX 版），支持复制与下载（`navigator.clipboard` + Blob）。
- **说明**：Vue 版生成 vue2/3 代码，React 版生成 TSX 产物，属合理差异；纯前端、无后端接口。

### 8.12 帮助中心（`/help`，权限 help）
- 静态页：系统标题/版本/版权 + GitHub 仓库与官方文档按钮（新窗口）+ GitHub star 数 iframe，对齐 Vue help.vue。

### 8.13 异常页
- 保留 ant-design-pro `exception/403|404|500`（样式遵循 antd-pro），路由兜底指向 404。

## 十、本地开发与联调

- 后端：本地启动 `xxl-boot-api`（默认 8081）。
- 前端 `config/proxy.ts` 新增 `dev` 代理（ant-design-pro 的 dev 代理默认注释，需补）：

```ts
dev: {
  '/api/': {
    target: 'http://localhost:8081',
    changeOrigin: true,
    pathRewrite: { '^/api': '' },   // 后端无 /api 前缀，需剥掉（对齐 Vue proxy）
  },
},
```

- 启动：`npm install && npm run dev`（Node >= 22）；后端改端口时调整 proxy。
- 业务不使用 mock，全部走真实后端；保留 ant-design-pro 的 mock 机制不启用（`MOCK=none`）。
- 接口路径与 Vue 版一字不差（如 `/authz/user/pageList`、`/authz/user/updatePwd?oldPassword=&newPassword=`），参数序列化兼容 `ids[]`。

1. `npm run dev` 可启动，无 TS/构建错误；`npm run lint`（biome + tsc）通过。
2. 登录：验证码开关生效、记住密码控制 token 有效期；登录成功跳转目标页，失败提示并刷新验证码。

4. 菜单与后端 `/getRouters` 一致（含隐藏、图标）；无权限用户看不到菜单且直接 URL 访问被拦截。
5. 各模块 CRUD/分页/排序/导出/授权树等交互与 Vue 版一致，数据接口未做任何后端改动。
6. 会话过期（301）弹窗重登；网络异常/超时提示文案与 Vue 一致。

## 十二、风险与待确认事项

| 项 | 说明 | 处置 |
| --- | --- | --- |
| 表单构建生成产物 | Vue 版生成 Vue 代码；React 版改为生成 TSX | 方案内已声明，属合理差异 |
| 菜单遗留图标 `fa-*` | DB 默认数据 icon 为 font-awesome 风格 | 建立 `fa-*→antd` 图标映射表兜底；资源编辑页用 antd 图标集选择 |
| 多语言维护 | 业务文案仅维护 zh-CN | locale 固定 zh-CN，其余语言包可后续镜像 |
| 后端新增菜单 vs 静态路由 | 后端菜单新增路径无对应页面会 404 | 菜单以后端数据渲染，页面按本方案静态注册，后续按需补充 |
| 消息富文本 XSS | 详情用 HTML 渲染（Vue 同 `v-html`） | 保持与 Vue 一致，如需要可加 sanitize 白名单 |
| react-quill 与 antd6 样式 | 富文本工具栏样式需微调 | 通过 less 变量 / 局部样式适配 |
| `@dnd-kit` 复杂度 | 代码生成字段排序、表单构建拖拽 | 拆两个独立实现，字段排序优先（简单表格行拖拽） |


确认信息补充：
- 1、菜单图标：不需要兼容历史逻辑，直接使用 antd 的图标。新建 `tables_xxl_boot_modular_react.sql` 将存量菜单数据的图标更新为 antd 图标，后续新增菜单直接使用 antd 图标即可。
- 2、不需要实现多语言；
- 3、菜单以后端数据为主，部分固定的静态菜单（如登录页、个人中心、帮助中心、异常页）按本方案静态注册，参考 vue 方案。
