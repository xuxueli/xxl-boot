# XXL-Boot React 版（xxl-boot-ui-react2）技术方案

> 基于 Ant Design Pro 设计体系实现，构建层已「去 Umi 化」，采用 **Vite + React Router + Zustand + TanStack Query** 组合；后端统一对接 xxl-boot-api，接口与数据结构不改动。

---

## 一、目标与范围

在 `xxl-boot-ui-react2/` 下提供 React 中后台前端，样式/组件/交互遵循 Ant Design Pro 规范；业务功能与 `xxl-boot-ui`（Vue 版）保持一致，后端接口原样对接。

| 模块 | 页面 | 说明 |
| --- | --- | --- |
| 认证 | 登录 | 账号密码 + 验证码（开关由后端控制）+ 记住密码（token 有效期） |
| 个人中心 | 基本信息 / 修改密码 | `/user/profile`，从头像下拉进入 |
| 首页 | Dashboard | 指标卡片 + 审计日志 ECharts 趋势图 + 站内消息 |
| 权限管理 | 用户管理 / 角色管理 / 资源管理 / 组织管理 | 含按钮级权限、资源-角色授权树 |
| 系统管理 | 字典管理 / 配置管理 / 站内消息 / 审计日志 | 含字典数据页、消息富文本、日志导出 |
| 系统工具 | 代码生成 / 表单构建 | 代码生成对接后端；表单构建为纯前端设计器 |
| 帮助中心 | /help | 静态页 |

## 二、技术选型

| 能力 | 方案 | 说明 |
| --- | --- | --- |
| 构建/开发服务器 | **Vite 8** + `@vitejs/plugin-react` | 替代原 Umi Max；`vite.config.ts` 配置别名/代理/构建 |
| 语言 | TypeScript 7 | 全量类型 |
| 路由 | **React Router v7**（`createBrowserRouter` + `RouterProvider`） | 替代 Umi 路由；含 RequireAuth / RequirePermission 守卫 |
| 状态管理 | **Zustand 5** | 会话、权限、菜单、布局设置（替代 Umi model + @@initialState） |
| 服务端状态 | **TanStack Query 5** | 枚举加载、首页统计/趋势/消息等数据缓存 |
| 请求 | **axios 1** + 自研 `utils/request.ts` | 替代 Umi request；token 注入/参数序列化/301/防重复提交 |
| UI 组件库 | `antd` 6 + `@ant-design/pro-components` 3 | ProLayout / ProTable / ProForm / PageContainer |
| 样式方案 | `antd-style`（createStyles / CSS-in-JS）+ `global.css` | 替代 Umi 的样式接入 |
| 图标 | `@ant-design/icons` | 全局图标 |
| 图表 | `echarts` | 首页审计日志折线图（对齐 Vue 版） |
| 富文本 | `react-quill` | 站内消息内容编辑（对齐 Vue 版 vue-quill） |
| 拖拽 | `@dnd-kit/core/sortable/utilities` | 代码生成字段排序、表单构建画布 |
| 会话存储 | `js-cookie` | Cookie `Admin-Token`，请求头 `xxl-sso-login-token` |
| 时间 | `dayjs` | antd 联动 |
| 代码规范 | Biome + `tsc` | `npm run lint` |
| 运行环境 | Node >= 22.12 | Vite 8 要求 |

## 四、全局基础设施

### 4.1 构建（`vite.config.ts`）
- 别名：`@` → `src`，`@root` → 项目根目录。
- 开发代理：`/api` → `http://localhost:8081`，剥离 `/api` 前缀。
- 开发端口 8000。

### 4.2 请求层（`utils/request.ts`，axios）
- `baseURL: '/api'`，服务层接口路径与 Vue 版一致（如 `/auth/login`）。
- 请求拦截：注入 `xxl-sso-login-token`；数组参数序列化 `ids[]=1&ids[]=2`、嵌套对象展开 `key[sub]=v`；POST/PUT 防重复提交（1s 快照）。
- 响应拦截：`code===301` 弹出重新登录确认框；非 200 统一 `message.error`；HTTP 异常中文提示（网络断开/超时/状态码）。
- `skipErrorHandler` 元数据：登录检查等场景跳过错误弹窗。
- 下载走 `utils/download.ts`（fetch + blob）。

### 4.3 会话与状态（Zustand）
- `userStore`：`currentUser / menuData` + `login / fetchUserInfo / fetchMenuData / logout / hasPermi / hasRole`。
- token 存 Cookie（`Admin-Token`），记住密码 365 天 / 默认 2 小时。
- `settingsStore`：布局设置 + 设置面板开关。

### 4.4 路由与守卫（`router.tsx`）
- `/user/login` 无布局；其余业务路由挂在 `BasicLayout` 下。
- `RequireAuth`：未登录重定向 `/user/login?redirect=...`；已登录但会话未加载时拉取用户信息与菜单。
- `RequirePermission`：按权限字符串（如 `authz:user`）拦截，无权限跳转 `/exception/403`。

### 4.5 菜单与面包屑
- 菜单数据源：后端 `/getRouters`（`userStore.menuData`），`BasicLayout` 的 `menuDataRender` 渲染；根级菜单做单子节点提升。
- 图标：后端返回 antd 图标名 → `getIconComponent` 映射。
- 面包屑：`breadcrumbProps.minLength: 1` 保证单层级页面（首页/帮助中心）也展示；`itemRender` 只读展示。

### 4.6 国际化
- 业务为中文，不使用多语言；`antd` 通过 `ConfigProvider locale=zh_CN` 本地化，文案全部硬编码中文。

## 五、登录页（`src/pages/user/login/index.tsx`）

- `LoginForm`（antd-pro）布局：logo、标题、账号、密码、验证码（开关/点击刷新）、记住密码。
- 挂载时 `GET /auth/captcha`；登录失败刷新验证码。
- 提交：`userStore.login` → 成功后 `message.success('登录成功！')` → `fetchUserInfo + fetchMenuData` → 停留 800ms → `navigate(redirect || '/dashboard')`。
- `redirect` 参数做防开放重定向校验。

---

## 六、个人中心（`/user/profile`）

- 左：`Card` + `Descriptions` 个人信息（账号/手机/邮箱/部门/角色/创建时间，`GET /authz/user/loadProfile`）。
- 右：`Tabs` 基本资料（`ProForm`，`updateProfile`）/ 修改密码（旧/新/确认，`updatePwd`）。
- 表单按钮：保存 / 重置 / 关闭（关闭返回上一页或首页）。

---

## 七、布局与头部（`BasicLayout.tsx`）

- `ProLayout`：后端菜单、`HeaderMessage` 消息铃铛、`AvatarDropdown`（个人中心 / 主题设置 / 退出登录）、`Footer`、`SettingDrawer` 设置面板（隐藏浮动快捷按钮，仅从下拉进入）。
- 退出登录：`Modal.confirm('确定注销并退出系统吗？')` → `logout` → 跳登录页。
- 退出/登出通过 `react-router` `navigate` 实现。

## 八、页面实现清单

> 通用约定：ProTable 分页 `current/pageSize → offset/pagesize` 服务层转换；枚举下拉用 `useEnumOption`（TanStack Query 缓存）；树表平铺转树 + 差量排序；删除走 `ids[]`；按钮权限 `usePermission().hasPermi/hasRole`。

### 8.1 首页 Dashboard
- 指标卡片 ×4（`GET /dashboard/stats`）。
- ECharts 折线图（`GET /dashboard/logTrend`，7/14/30 天切换，`useQuery` 缓存）。
- 站内消息列表 + 详情抽屉（`listMessageTop / markRead`）。

### 8.2 用户管理（`authz:user`）
- 左组织树（TreePanel）+ 右侧 ProTable；状态 Switch、重置密码、详情 Drawer。

### 8.3 角色管理（`authz:role`）
- ProTable + 菜单权限树（展开/折叠/全选/父子联动），保存角色后调 `updateRoleRes`。

### 8.4 资源管理（`authz:resource`）
- 树表 + 图标选择（IconSelect）+ 内联排序差量保存。

### 8.5 组织管理（`authz:org`）
- 树表 + 内联排序 + 防环校验。

### 8.6 字典管理（`system:dict`）+ 字典数据（`/system/dict/data`）
- 类型页 ProTable + 数据抽屉；数据页为隐藏路由（`dictId` 从 query 读取）。

### 8.7 配置管理（`system:config`）
- ProTable + 表单（key 编辑禁用）。

### 8.8 站内消息（`system:message`）
- ProTable + 富文本（react-quill）+ 详情抽屉 + 已读用户弹窗。

### 8.9 审计日志（`system:log`）
- ProTable + 枚举筛选 + 导出（POST blob）+ 详情（复制）。

### 8.10 代码生成（`tool:codegen`）
- ProTable + 创建表 + 编辑（配置信息 + 可拖拽字段表，@dnd-kit）+ 预览 + 批量生成 zip。

### 8.11 表单构建（`tool:pagegen`）
- 三栏拖拽设计器（组件面板/画布/属性面板），生成 TSX 代码，纯前端。

### 8.12 帮助中心 / 异常页
- 静态页（按钮 + GitHub star 徽章 + Powered by XXL-BOOT v…）；403/404/500 由 React Router 渲染。

## 十、本地开发与联调

- 后端：启动 `xxl-boot-api`（默认 8081）。
- 前端：`npm install && npm run dev`（Vite，端口 8000，`/api` 代理到 8081）。
- `npm run build` 生产构建；`npm run preview` 预览。
- 接口路径与 Vue 版一字不差，参数序列化兼容 `ids[]`。

## 十一、验收标准

1. `npm run lint`（biome + tsc）通过；`npm run build` 成功。
2. 登录（验证码开关/记住密码）→ 跳转目标页；会话过期（301）弹窗重登。
3. 个人中心信息/改密与 Vue 一致。
4. 菜单与后端 `/getRouters` 一致；无权限用户看不到菜单且直接 URL 被拦截（403）。
5. 各模块 CRUD/分页/排序/导出/授权树与 Vue 一致，后端接口未改动。
6. 首页 ECharts 趋势图 X 轴横向稀疏展示。

## 十二、风险与待确认事项

| 项 | 说明 | 处置 |
| --- | --- | --- |
| react-quill 与 React 19 | 兼容性一般 | 若异常可换 TipTap/Lexical |
| ECharts 体积 | 打包体积较大 | 可按需引入 `echarts/core` 树摇优化 |
| 表单构建生成产物 | 生成 TSX（Vue 版生成 Vue 代码） | 合理差异 |
| 后端新增菜单 vs 静态路由 | 无对应页面会 404 | 菜单以后端数据渲染，页面静态注册，按需补充 |
| 消息富文本 XSS | 详情用 HTML 渲染 | 与 Vue 版一致，如需可加 sanitize |
