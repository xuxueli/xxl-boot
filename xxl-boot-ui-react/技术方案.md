# XXL-Boot UI React 版技术方案

> 项目：`xxl-boot-ui-react`
> 目标：使用 React 100% 复制 `xxl-boot-ui`（Vue3 版）的功能与交互，外观采用 Ant Design 风格。
> 状态：已实施完成（M0–M6 全部完成）

## 1. 项目背景与目标

- 源项目 `xxl-boot-ui`：Vue 3.5 + Vite + Pinia + Vue Router + Element Plus，约 2.3 万行源码（视图 8k / 布局 4k / 组件 4k / 基础设施 5k / 类型 1k）。
- 目标：在 `xxl-boot-ui-react` 下用 React + TS 重写，后端接口、`Response`/`PageModel` 数据结构、动态菜单、RBAC 权限模型均不变。
- 验收标准：**功能与交互 100% 对齐**；视觉采用 antd 风格，不做像素级复刻。

## 2. 技术选型

| 维度 | 选型 | 说明 |
|---|---|---|
| 构建工具 | Vite 8 + TypeScript（strict） | 保留 `import.meta.glob`、环境变量、`/api` 代理、gzip/brotli 压缩 |
| UI 组件库 | Ant Design v5 | `ConfigProvider` + zhCN locale + `theme.darkAlgorithm`（暗色） |
| 状态管理 | Zustand + `persist` 中间件 | 替代 6 个 Pinia store 与手写 localStorage 持久化 |
| 路由 | react-router v6/v7 | 数据驱动路由模拟动态注入；扩展自定义 `RouteObject.meta` |
| 页面缓存 | react-activation | 等价 `<keep-alive>`；`dropByCacheKey` 实现「刷新」重挂载 |
| HTTP | axios（拦截器逻辑复用） | `request.ts` 大部分为框架无关代码 |
| 富文本 | `@react-quill` + Quill 2 | 等价 `@vueup/vue-quill` |
| 图表 | echarts 6 | dashboard 复用 |
| 拖拽 | `@dnd-kit/core`（pagegen）/ sortablejs（FileUpload/ImageUpload 排序） | 替代 vuedraggable |
| 其他 | fuse.js、nprogress、js-cookie、file-saver、clipboard、js-beautify | 原样复用 |

## 4. 基础设施层设计

### 4.1 请求层 `utils/request.ts`
照搬拦截器逻辑：
- 请求：token 注入（header `xxl-sso-login-token`，`isToken:false` 跳过）→ GET 参数 `tansParams` 序列化 → POST/PUT 防重复提交（sessionStorage `sessionObj`，FormData/Blob/>5M 放行）。
- 响应：blob/arraybuffer 透传 → code 301 弹「重新登录」（`isRelogin.show` 防重复）→ 非 200 `modal.msgError` → 200 返回 `res.data`。
- 替换点：`modal`（ElMessage→antd `message`/`Modal.methods`）、`useUserStore`（→Zustand hook）。
- 保留导出：`request<T>`、`download`、`errorCode`、`isRelogin`、默认实例。

### 4.2 状态层 `stores/`（Zustand）

| Store | State | Actions | 持久化 key |
|---|---|---|---|
| user | token/id/name/realName/roles/permissions | login/getInfo/logout + hasPermi/hasPermiOr/hasPermiAnd/hasRole/.../checkPermi/checkRole | Cookie `Admin-Token` |
| routes | dynamicRoutes/flattenRoutes/_scope | initRoutes/getFlattenRoutes/setScope + transformRoutes/loadView/setFirstAffix/filterChildren | — |
| app | sidebar{opened,withoutAnimation,hide}/device/size | toggleSideBar/closeSideBar/openSideBar/hideSideBar/toggleDevice/setSize | `boot-sidebar-status`、`boot-fontsize` |
| settings | 15 个布局/主题字段 | initSetting/saveSetting/resetSetting/toggleTheme/setSideTheme/setTheme/setMenuTitle/setNavType/... | `boot-layout-setting` |
| tagsView | visitedViews/cachedViews | addView/delView/delOthers/delAll/delLeft/delRight/updateView/loadPersistedViews/clear | `tags-view-visited`（可选） |
| dict | dict[{key,value}] | getDict/setDict/removeDict/cleanDict/initDict | — |

要点：
- 主题色注入 `utils/theme.ts#handleThemeStyle` 保留算法（`mixHexColors`/`getLightColor`/`getDarkColor`），CSS 变量由 `--el-color-*` 改为 `--current-color` 系列（antd `ConfigProvider` theme token + 自定义变量）。
- 暗色模式：`document.documentElement.classList` 切换 `.dark` + antd `theme.darkAlgorithm` 联动。
- `setMenuTitle`：动态标题逻辑照搬（`menuTitle + ' - ' + title`）。

### 4.3 路由与守卫
- **静态路由**：login、`''`→redirect `/dashboard`、`/user/profile/:activeTab?`、`/redirect/:path(.*)`、`/301`、`/:pathMatch(.*)*`→404。
- **动态路由**：后端 `/getRouters` 菜单树 → `transformRoutes`（`Layout`/`ParentView`/`InnerLink` 特判 + `import.meta.glob('../views/**/*.tsx')` + `React.lazy`）→ 写入 routesStore，重组 `<Routes>`。首屏初始化完成后重新渲染即等价 Vue 版 `{...to, replace:true}`。
- **守卫组件**：包裹 `<Routes>`。
  1. `/login` 白名单放行；
  2. 有 token 且访问 `/login` → 重定向 `/`；
  3. `roles.length===0` → `getInfo()` + `initRoutes()`，异常 → `logout()` + 报错回首页；
  4. 无 token → `/login?redirect=xxx`。
  5. `afterEach` 等价：NProgress + `setMenuTitle`。
- **businessRoutes**：`/system/dict/data` 隐藏路由照搬。

### 4.4 权限与指令
- `v-hasPermi`/`v-hasRole` → `<Auth perms roles>` 条件渲染（不渲染 = 等价移除 DOM），内部复用 `checkPermi`/`checkRole`（含 `*:*:*`、`admin` 通配）。
- `v-copyText`/`v-copyText:callback` → `useCopyText` hook（hidden textarea + `document.execCommand('copy')` + 选区恢复）。

### 4.5 页面缓存（react-activation）
- `AppMain`：`useOutlet()` → 每个路由包 `<KeepAlive name={componentName} cacheKey={path}>`。
- TagsView「刷新」：`dropByCacheKey(key)` 后重挂载，等价 `delCachedView` + `/redirect`。
- `cachedViews` 由 tagsViewStore 维护，作为缓存白名单。

## 5. 布局层设计

`Layout` 组合：`Sidebar`（或三模式导航）+ `Navbar` + `TagsView` + `AppMain` + `Settings` 抽屉。

| 模块 | 关键行为 |
|---|---|
| Sidebar | `el-menu`→antd `Menu`（inline，折叠态）；`sidebarRouters` 按 `_scope` 过滤；SidebarItem 递归 + 「唯一子节点提升」逻辑；外链识别；Logo |
| Navbar | Hamburger + Breadcrumb（navType1）/ TopBarMix（2）/ TopBar（3）；右侧 HeaderSearch/Fuse.js、Screenfull、主题切换（View Transition 动效降级）、SizeSelect、HeaderMessage（未读徽标+抽屉详情）、用户下拉（个人中心/布局设置/退出） |
| TagsView | 标签栏 + ScrollPane 平滑滚动 + 右键菜单（关闭/关闭其他/关闭左侧/关闭右侧/关闭全部）+ card/chrome 两种样式 + affix 固定首页标签 + 页面级全屏 |
| AppMain | Outlet + KeepAlive + 页面过渡（react-transition-group 或纯 CSS）+ Copyright |
| Settings | 抽屉：navType 三模式、主题色 ColorPicker+10 预设、暗/亮侧栏主题、tagsView/tagsIcon/固定头部/动态标题/页脚 等开关 + 保存/重置 |
| 响应式 | `<992px` 移动端抽屉侧栏；窗口尺寸监听（自定义 hook 替代 VueUse） |

- 列表页通用操作：`getList/handleQuery/resetQuery/handleAdd/handleUpdate/handleDelete/submitForm/handleSelectionChange`。

## 8. 表单生成器（pagegen）改造

- 拖拽：vuedraggable → `@dnd-kit/core`（克隆克隆、跨区拖放、排序）。
- 生成器 `utils/generator/*`：
  - `config.ts`：组件注册表（input/select/layout 三类）+ `trigger` 映射 + `beautifierConf` → **组件标签改为 antd**（`el-input`→`Input` 等），`trigger` 改为 antd 规则。
  - `html.ts` / `js.ts` / `render.ts`：改为生成 **React + antd** 表单代码（`Form`/`Form.Item`/`Input`...）。
  - `css.ts`、`drawingDefault.ts` 基本复用。
- 生成的代码风格：函数组件 + hooks，输出可在 React 工程直接使用。

## 9. 环境与工程配置

- `.env.*`：与 Vue 版一致（`VITE_APP_ENV`、`VITE_APP_PORT=3000`、`VITE_API_URL=http://localhost:8081`、`VITE_APP_BASE_API=/api`）。

- `tsconfig.json`：strict、`@/*` 与 `~/*` 别名、`vite/client` 类型。
- 脚本：`dev` / `build:prod`（`tsc --noEmit && vite build`）/ `lint`（eslint + prettier）/ `preview`。
- `Dockerfile`：静态资源 nginx 部署（参照 Vue 版）。

## 11. 工作量与风险

- **工作量**：utils/types/api 可直接拷贝（节省约 40%）；视图/布局/组件需 JSX 重写，全量估算 **3–4 周**。
- **风险与对策**：
  1. TagsView 刷新/缓存 → 先做 react-activation POC（M3 前置验证）。
  2. antd 与 Element Plus 语义差异（表单校验、Table 列渲染、Menu 递归）→ 每页逐个适配，先出「样板页」（如 message）。
  3. pagegen 拖拽与代码生成 → 依赖组件标签映射，提前定义 `el-x`→antd 映射表。
  4. 动态路由刷新重建 → 数据驱动路由模式，路由状态收敛到 store。

## 12. 代码规范（沿用 AGENTS.md）

- 中文沟通与注释；文件头注释 `@author xuxueli yyyy-mm-dd`；方法/分支中文注释。
- 命名：组件 PascalCase、hooks `useXxx`、常量全大写、`ref` 状态用 `useState`，一组相关状态收敛为对象 state（`queryParams`/`table`/`formState`）。
- 页面 `ref data → fun → page init` 三段式结构；避免过度设计、保持各页写法一致。
- 分页入参统一 `offset/pagesize`；响应从 `response.data` / `response.data.data` 取数。
